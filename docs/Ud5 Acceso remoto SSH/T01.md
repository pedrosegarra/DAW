# El cliente SSH a fondo

SSH tiene dos extremos: el servidor (`sshd`), que espera conexiones, y el cliente (`ssh`), desde el que te conectas. En esta unidad trabajas el cliente y su fichero de configuración, `~/.ssh/config`: alias, una clave para cada destino, saltos por un bastión, túneles y diagnóstico.
